# `IAlignedTextStyle`

Defines the visual style applied to an aligned text fragment in an exported PDF document.

Available since: v3.0.0

## Inheritance

[`ITextStyle`](https://surveyjs.io/pdf-generator/documentation/api-reference/itextstyle.md) &rarr; `IAlignedTextStyle`

## Properties

### `textAlign`

**Type**: `"center" | "left" | "right"`

Specifies the horizontal alignment of the text.

Possible values:

- `"left"`
- `"right"`
- `"center"`

Available since: v3.0.0
